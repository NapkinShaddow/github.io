Privacy Policy — Napkin666

Last updated: October 20, 2026

Napkin666 Local Google Docs Connector is a personal, non-commercial utility operated by the Google account owner to perform expressly authorized Google Docs operations through a controller on the owner's computer. This policy describes the experimental connector currently being tested, not any future unapproved production integration.

Separate application: Napkin666 is not the same as Napkin Shadow ReadOnly. The older utility reads and synchronizes selected Drive files; Napkin666 is designed to read and write Google Docs within the permissions granted by the account owner.

Google account data accessed

With the owner's explicit Google OAuth authorization, the connector uses the Google Drive drive.file scope and Google Docs API. This scope permits access to files created by the application or explicitly made available to it. The application may create test documents, read their contents and metadata, append authorized text, and verify changes by reading them back. It does not request blanket access to every Drive file.

At present, tests are confined to specifically designated private test documents. Access to existing Napkin production documents is not enabled by this experimental connector and would require separate authorization and safeguards.

Why the data is used

Google data is used solely to carry out and verify actions requested or authorized by the account owner, including confirming the exact document, avoiding duplicate writes and detecting conflicting edits. Google account data is not used for advertising, profiling, or sale.

Storage, retention, and security

The current test runs on the owner's Windows computer. Access tokens are held in process memory for the active operation; an OAuth refresh token for renewed access is stored on that computer encrypted for its Windows user by the Windows Data Protection API (DPAPI). No OAuth token or Google document content is intentionally published to this GitHub Pages site. Private test documents remain in the owner's Google Drive until the owner deletes them.

The local controller may retain minimal operational status and diagnostic information needed to check whether authorized test actions completed. Do not place credentials or private document contents into public GitHub issues. GitHub, as website host, may process ordinary visits to this public information site under its own privacy terms.

Sharing and use restrictions

The connector does not sell or share Google user data with advertisers or data brokers. The current standalone test does not intentionally transmit Google document contents to third-party AI models or an unrelated external service. Any future integration that would disclose account data beyond the owner's authorized Google API operation will require a separate review and an accurate policy update before activation.

Use and transfer of Google API data are subject to the Google API Services User Data Policy, including its Limited Use requirements where applicable.

Owner control

The owner can revoke the application's Google access in Google Account connections, delete documents created by the test, and delete the locally stored encrypted refresh-token file. Revocation can prevent future API access; it does not itself delete preexisting test documents.

Contact and policy updates

Questions about this personal utility may be raised at the project's GitHub repository issue page. Please do not include personal data, document contents, credentials, or tokens in public issues. This policy will be updated if the connector's authorized processing materially changes.

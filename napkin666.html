Napkin666 — Local Google Docs Connector

Napkin666 is a personal, non-commercial local utility for the owner of a Google account. Its purpose is to execute explicitly authorized Google Docs API operations through the owner's computer, rather than relying on a conversational application's document connector.

What the application does

With Google OAuth authorization, the application can create test documents, read their contents, append text to authorized documents, verify exact readback, and detect duplicate or conflicting writes. It uses the drive.file scope for files created by or explicitly made available to the application.

The current version is an isolated private test. It is not a publicly available service, and it does not currently write to Napkin production documents. Expanding its document access or deploying it in production requires separate approval and controls.

Owner control and privacy

Google access requires explicit consent. The owner can revoke access in Google Account settings. The local experimental connector encrypts its refresh token with Windows Data Protection API under the current Windows user account. The application does not publish private documents on this website.

See the Napkin666 Privacy Policy for details about Google data use, storage, and revocation.

# Privacy Policy — Napkin Shadow ReadOnly

**Last updated: October 8, 2026**

## Overview

Napkin Shadow ReadOnly is a personal, non-commercial utility used by the application owner to synchronize Google Drive documents with a local reference database.

## Google Drive Access

The application requests read-only access to Google Drive through Google OAuth.

Access is used to retrieve documents for the owner's personal Napkin workspace. The application does not modify or delete files in Google Drive.

## Data Storage and Use

Retrieved information is stored locally on the owner's computer for synchronization and reference purposes.

This utility does not sell Google user data, use it for advertising, or intentionally make retrieved documents publicly available.

## Access and Retention

The owner controls the local database and can delete its stored data.

Google account access can be revoked at any time through Google Account security settings.
